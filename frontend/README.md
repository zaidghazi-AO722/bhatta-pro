# Role Sidebar Layouts

This folder contains only the requested React + Tailwind CSS sidebar layouts.

## Components

- `SuperAdminSidebar`: Tenant Management, License Matrix, System Logs, Server Backups, Maintenance Mode.
- `BusinessOwnerSidebar`: Store Setup, Staff Accounts, Tax Settings, Invoice Customizer, Local Backup.

Both layouts are responsive, collapsible, keyboard/button accessible, and visually separated by role. No existing application files are modified by these additions.

## Dependency

The component expects React and `lucide-react`, with Tailwind CSS configured in the host React application.
