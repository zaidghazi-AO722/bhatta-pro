# Premium Dashboard UI

Added only the requested React + Tailwind presentation layer in `PremiumDashboard.jsx`.

Includes:
- Smooth glassmorphism and backdrop blur
- Animated/collapsible sidebar transitions
- Dynamic background graphics and animated chart bars
- Button/card hover and active effects
- Skeleton loading state
- Responsive desktop/mobile layout
- Role-aware navigation labels for OWNER, MANAGER, and CASHIER

This component is presentation-only. It does not modify JWT/RBAC, tenant isolation, database queries, authentication, or existing application logic.
